# AI-Generated-vs-Human-Arduino-Firmware-Dataset

This repository contains a curated dataset of Arduino firmware source code samples designed for detecting AI-generated code using stylometric analysis. The dataset includes both human-written and AI-generated firmware programs, enabling research in code authorship attribution and AI code detection within embedded systems.

The dataset consists of 180 Arduino firmware samples, including:

90 human-written programs collected from official Arduino libraries (pre-2019)
90 AI-generated programs created using Large Language Models (LLMs) based on equivalent project descriptions

Each pair of samples represents the same functional requirement, ensuring a balanced and controlled comparison between human and AI-generated code.
